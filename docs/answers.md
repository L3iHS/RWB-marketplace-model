# Ответы на вопросы аналитиков

Запросы — в [answers/](../answers/), все считаются из витрин `mart`,
не из `raw` (это проверяет тест). Готовые результаты в CSV и JSON —
в [artifacts/answers/](../artifacts/answers/), пересобрать: `make answers`.

Посмотреть результат одного запроса:

```bash
bash build.sh answers/01_monthly_revenue.sql
```

Сверка всех ответов с контрольными цифрами: `make check`.
Все 10 контрольных значений совпадают; при расхождении команда падает с ошибкой.

## Общие определения

| Термин | Определение |
|---|---|
| Выручка | Сумма `price` позиций доставленных заказов, без стоимости доставки |
| Средний чек | Сумма `price + freight_value` заказа, усреднённая по доставленным заказам |
| Покупатель | Человек, `customer_unique_id` |
| Месяц | Месяц оформления заказа |

## 3. Средний чек

[answers/03_average_order.sql](../answers/03_average_order.sql)

| Средний чек | Строк в заказе | Единиц в заказе |
|---:|---:|---:|
| **159.88** ✓ | 1.0385 | 1.1422 |

Строка чека — товар одного продавца в заказе. Единица — одна строка
`order_items`. Единиц больше, чем строк: иногда покупают несколько
одинаковых товаров.

Задание просит два числа, чтобы проверить уровень расчёта. Если считать
строкой чека строку `order_items`, оба числа совпадут (1.1422 и 1.1422,
так было в первой версии `main`), и проверка ничего не покажет.

## 4. Покупатели и повторные покупки

[answers/04_repeat_customers.sql](../answers/04_repeat_customers.sql)

| Покупателей | Вернулись | Доля |
|---:|---:|---:|
| **96 096** ✓ | 2 997 | **3.12%** ✓ |

Считаем заказы всех статусов. Возвращение — это поведение покупателя:
он пришёл и оформил заказ снова. Если потом заказ отменил продавец
или товара не оказалось, покупатель всё равно вернулся.
Только по доставленным заказам: 93 358 покупателей, 3.00%.
